# 성경 구절 조회

각자의 컴퓨터나 아이폰에 있는 성경 TXT 파일을 선택해 조회하는 웹페이지입니다.

## 사용 방법

1. 웹페이지를 엽니다. 로컬에서 실행할 때는 이 폴더에서 `python -m http.server 5500`을 실행하고 `http://localhost:5500`에 접속합니다.
2. PC에서는 **TXT 폴더 선택**으로 기존 `data` 폴더를 선택합니다.
3. 아이폰에서는 ZIP을 파일 앱에 저장한 다음, Safari에서 페이지의 **ZIP 파일 선택**으로 선택합니다. ZIP 안에 TXT가 바로 있어도 되고 폴더 안에 있어도 됩니다.
4. 구절을 한 줄에 하나씩 입력하고 조회합니다. `베드로후서 1:4-7`과 `베드로후서 1장 4-7절`을 모두 지원합니다.
5. **전체 복사**로 정상 조회 결과를 복사합니다. 아이폰에서는 HTTPS 주소에서 사용합니다.

본문은 서버로 보내지 않고 브라우저 메모리에서만 읽습니다. 새로고침하거나 페이지를 닫으면 다시 선택해야 합니다.

## 파일 선택

- `1-01창세기.txt`, `2-22베드로후서.txt` 등 기존 파일 이름을 유지합니다.
- 66권 전체 또는 필요한 책의 TXT만 선택할 수 있습니다. 선택하지 않은 책은 조회 시 안내합니다.
- ZIP은 암호가 없는 일반 ZIP을 사용합니다. 한글 파일 이름과 기존 CP949 본문, UTF-8 본문을 지원합니다.
- 새 파일 선택은 기존 선택을 대체합니다. 읽기에 실패하면 이전 선택과 조회 결과를 유지합니다.
- iOS 18.4 이상 Safari에서는 폴더 선택도 지원합니다. 아이폰에서는 ZIP 파일 하나를 선택하는 방법을 권장합니다.

## GitHub에 올릴 파일

`index.html`, `css/`, `js/`, 이 README와 `.gitignore`를 올립니다. ZIP 기능에 필요한 `js/vendor/`도 포함합니다.

`.gitignore`는 `data/`와 ZIP 파일을 Git 추적에서 제외합니다. 이미 Git이 추적하는 파일에는 소급 적용되지 않습니다. 웹사이트에 직접 파일을 올릴 때도 본문 TXT와 ZIP을 포함하지 않습니다.

프로그램은 TXT를 자동 다운로드하지 않습니다. 각자가 이용할 수 있는 본문 파일을 준비해 선택합니다. 파일 형식 변경이나 ZIP 압축은 본문 이용·재배포 허락을 대신하지 않습니다.

## ZIP 라이브러리

JSZip을 프로그램과 함께 보관하므로 외부 CDN에 접속하지 않습니다. 버전과 원본 라이선스는 `js/vendor/README.md`, `js/vendor/JSZIP-LICENSE.md`에 있습니다.
